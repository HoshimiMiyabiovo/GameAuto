## 三、五个阶段

### 阶段一：萌芽（2025-02 ~ 2025-07，DeepSeek 问答期）
以大学课程问答为主（编译原理 LR 分析、图形学、计网），项目种子混在其中：
- **2025-03**「游戏自动化任务配置变更」——项目最早痕迹
- **2025-04**「更换 StarRail 脚本并保留 March7th 配置」——星铁自动化的起点

### 阶段二：前身项目（2025-08 ~ 2025-12，Trae CN 主战场）
**对话正文缺失**（Trae CN 的 ChatStore 加密），但有实物互证：
- `data/logs/runner.log/` 的 36 天前身运行日志（2025-09-26 ~ 2025-11-23，最老的
  `auto_runner.log.1` 从 09-26 起 3.4MB）——就是那个时期的 auto_runner 在跑
- 功能形态可从日志辨认：键盘诊断、`keyboard` 库快捷键、qbittorrent.exe 进程匹配——
  都是后来重构掉的早期设计
- DeepSeek 侧同期 3172 条消息（2025-09 峰值），内容以课程（数据库/分布式/遗传算法）
  + YOLOv8 毕设方向为主

### 阶段三：毕设 + 重生（2026-01 ~ 2026-04，Cursor 期）
- 毕设线：滑坡标注 GIS 系统（Vue3 + GeoTIFF）、论文、YOLOv8
- 游戏自动化兴趣回归：**2026-01**「写一个 CV 自动玩俄罗斯方块的脚本」、
  **2026-04** GitHub Copilot「无限暖暖抽卡分析脚本开发指南」

### 阶段四：ok-* 脚本群 → game_auto 成型（2026-05 ~ 2026-07）
全史最密集的三个月（9877 条 / 228 万字）：
- **2026-05**：GitHub Copilot「添加 ok-nte 模块及启动流程问题」（**单会话 126 万字**，
  全史最大）；Codex「修正终末地每日活跃数据」；Claude Code 研究 OK-NTE 各脚本
  启动方式——ok-ww / ok-ef / ok-nte 脚本群在此期成型（现仍可见于
  `E:\GithubProject\autoGame`，本仓库以 script_tools 机制托管它们的安装）
- **2026-06**：Claude Code「Very thoroughly explore e:\GithubProject\game_auto\ui\automation」
